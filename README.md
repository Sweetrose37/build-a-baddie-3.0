# Build a Baddie 3.0 — The Look Lab

A from-scratch, local-first creative-direction studio for building production-aware prompts for original fashion artwork featuring glamorous adult Black women.

## Run locally

No dependencies, build step, account, or API key are required.

```powershell
node server.mjs
```

Open `http://localhost:4173`.

## What works

- Quick and Studio builder modes
- Six creative-direction sections with responsive live preview
- Complete 2.0 dropdown catalog: 85 dropdowns, 1,740 choices, and conditional holiday/game-day studios
- Progressive sub-tabs keep the full catalog organized without overwhelming the interface
- Four vibe presets
- Per-field locks and lock-aware full remixing
- “YOU A BAD GIRL” bold remix action for every unlocked choice
- Production-aware recipe compiler with anatomy, originality, print, and game-day safeguards
- Clipboard, Web Share, and TXT export
- Saved looks stored privately in localStorage
- Installable PWA shell and offline caching
- Responsive desktop, tablet, and mobile layouts

The editorial portrait and app icon are original AI-generated assets created specifically for 3.0. No data is uploaded or transmitted by the app.
